단진동 실험실

등속 원운동의 그림자부터 용수철 진자, 두 진자 비교, 물체의 분리까지 직접 움직여 보며 확인해요.

등속 원운동의 그림자 = 단진동

평행 광선을 비추면 원 위의 물체 그림자가 스크린에서 P와 Q 사이를 단진동해요. t = 0에 O′를 지나 위(+) 방향으로 출발해요.

각도로 바로 가기 (θ = ωt)

시간 t
각도 θ = ωt
변위 x = A sin ωt
속도 v = Aω cos ωt
가속도 a = −ω²x
ω = 2π/T  ·  최대 속력 Aω (평형점 O′)  ·  최대 가속도 Aω² (양 끝 P, Q)
가속도는 항상 평형점을 향한다 (변위와 반대 방향)

관찰 포인트

  • 그림자의 속도는 원운동 속도의 세로 성분, 가속도는 구심 가속도의 세로 성분이에요.
  • O′에서는 속도가 최대이고 가속도는 0, P·Q에서는 속도가 0이고 가속도가 최대예요.
  • 그래프에서 속도는 변위보다 1/4주기 앞서고, 가속도는 변위와 항상 반대 부호예요.

수평 용수철 진자

마찰 없는 면에서 물체를 +A까지 당겼다가 놓아요. 복원력은 항상 평형점 O를 향해요.

주기 T = 2π√(m/k)
변위 x
속도 v
가속도 a = −kx/m
복원력 F = −kx

역학적 에너지

운동 E
탄성 E
합

관찰 포인트

  • 진폭 A를 바꿔도 주기는 그대로예요. 주기는 m과 k로만 정해져요.
  • O에서는 운동 E가 최대, 양 끝에서는 탄성 E가 최대이고 합 ½kA²은 일정해요.

연직 용수철 진자

평형점 O(원래 길이에서 x₀ = mg/k 늘어난 곳)를 중심으로 단진동해요. 오른쪽 F–s 그래프의 점이 함께 움직여요.

상황

늘어난 길이 x₀ = mg/k
진폭 A
주기 T = 2π√(m/k)
탄성력 k(x₀+y)
중력 mg
알짜힘 = −ky

관찰 포인트

  • g를 바꾸면 평형점 O만 이동하고 주기는 그대로예요.
  • 원래 길이에서 놓으면 진폭 = x₀, 실을 끊으면 진폭 = Δmg/k (끊는 순간 정지한 위치에서 새 평형점까지 거리).
  • 평형점 기준으로 ½mv² + ½ky² = ½kA² 이 일정해요. F–s 그래프의 빨간 삼각형 넓이가 ½kA²이에요.

두 용수철 진자 비교

두 진자의 m, k, A를 따로 바꾸고 주기·최대 속력·에너지의 비를 확인해요. 아래 그래프에서 같은 변위가 되는 순간을 셀 수 있어요.

물리량㉠㉡㉠ : ㉡

관찰 포인트

  • 질량이 4배면 주기는 2배, k가 4배면 주기는 1/2배예요. 진폭은 주기와 관계없어요.
  • 최대 속력 = Aω, 최대 가속도 = Aω², 역학적 에너지 = ½kA² 로 비를 세워 보세요.

물체의 분리

용수철에 붙은 A 앞에 B를 붙여 놓고 용수철을 압축했다가 놓아요. 용수철이 원래 길이(O)가 되는 순간 B가 떨어져 나가요.

A의 위치B의 위치
분리 전 주기 2π√((mA+mB)/k)
분리 시각 (¼ 주기)
분리 순간 속력 v = A₀ω₁
분리 후 A의 주기 2π√(mA/k)
분리 후 A의 진폭 A′ = v/ω₂
지금 상태
분리 조건: B를 미는 힘이 0이 되는 순간 → A의 가속도가 0 → 평형점(원래 길이)
분리 후 B는 등속 운동, A는 같은 속력 v로 O를 지나는 새 단진동
에너지: ½mAv² = ½kA′² → A′ = A₀√(mA/(mA+mB))

관찰 포인트

  • 분리 순간까지는 A와 B가 함께 하나의 진자(질량 mA+mB)처럼 움직여요.
  • 분리 후 A의 주기는 짧아지고, 진폭은 A₀보다 작아져요. B는 v로 계속 등속 운동해요.
